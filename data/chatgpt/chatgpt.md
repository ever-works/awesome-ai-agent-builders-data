## Overview

ChatGPT is OpenAI's AI assistant platform with agentic capabilities through ChatGPT Work. Users describe a goal and ChatGPT works until the job is done, reading files, using connected apps, and producing documents, spreadsheets, decks, and interactive sites.

## Features

- ChatGPT Work: agentic mode where the model pursues a goal across multiple steps and tool calls
- Plan mode: approve the agent's approach before execution starts
- Projects: group instructions and files for recurring agent workflows
- Scheduled tasks: run agents on a repeating schedule (daily briefings, weekly reports)
- Shared workspace agents (Business and Enterprise): deploy agents in Slack or trigger via API
- Role-based admin controls and approval prompts on write actions
- Desktop app with local file access and computer control

## Pricing

- Free: limited access to ChatGPT Work
- Go: $8/month, limited access
- Plus: $20/month for regular use
- Pro: starting at $100/month for heavy users
- Business: $20/user/month billed annually, includes workspace agents
- Enterprise: custom pricing

## Deployment

Cloud-based (OpenAI's servers); desktop app available for local file access.
