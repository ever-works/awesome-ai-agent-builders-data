## Overview

Claude is Anthropic's AI assistant with agentic capabilities (Claude Cowork) built into the main chat experience. Users tell Claude what they want done, and it decides how to approach it: planning work, using files and connected apps, and checking in before sensitive actions.

## Features

- Claude Cowork: agentic mode where Claude plans and executes multi-step tasks
- File and app connectivity: access to connected data and applications
- Scheduled tasks: turn a process into a recurring hourly, daily, weekly, or weekday task
- Skills: package instructions for how a job should be done so Claude repeats it consistently
- Projects: hold files and context for Claude to reference
- Shared projects and admin controls (Team plan): organization-wide skills deployment
- Claude Code: developer tool for building software with Claude

## Pricing

- Free: includes skills, connectors, and projects; scheduled tasks need a paid plan
- Pro: $17/month billed annually, includes Claude Code and scheduled tasks
- Max: starting at $100/month for heavier use
- Team: $20/seat/month billed annually for 2 to 150 seats
- Enterprise: $20/seat/month plus usage at API rates, 20-seat minimum

## Deployment

Cloud-based (Anthropic's servers); desktop app available for local file tasks.
