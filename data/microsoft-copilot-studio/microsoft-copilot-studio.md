## Overview

Microsoft Copilot Studio is a no-code platform for building custom agents that publish to Microsoft 365, Teams, and the web. It uses Power Platform connectors behind the scenes and is best suited for organizations already running on Microsoft.

## Features

- No-code agent builder
- Publish agents to Microsoft 365, Teams, and the web
- Power Platform connectors for integration with Microsoft and third-party services
- Custom agent creation for enterprise use cases
