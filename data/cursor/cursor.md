## Overview

Cursor is a code editor with built-in AI agents, including cloud agents that run in the background. It provides developers with an environment for building and working with AI agents directly within their code editor.

## Features

- Built-in AI agents within the code editor
- Cloud agents that run in the background
- Developer-focused agent building environment
